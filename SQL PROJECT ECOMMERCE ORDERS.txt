1.How many orders are there in total, and how many in each order status?

SELECT ORDER_STATUS,COUNT(*) AS ORDER_COUNT
FROM ORDERS
GROUP BY ORDER_STATUS
ORDER BY ORDER_COUNT DESC;

2.How many orders were placed in each year?

SELECT SUBSTR(ORDER_PURCHASED_TIMESTAMP,1,4) AS ORDER_YEAR,COUNT(*) AS TOTAL_ORDERS
FROM ORDERS
GROUP BY SUBSTR(ORDER_PURCHASED_TIMESTAMP,1,4)
ORDER BY ORDER_YEAR;

3.How many orders have a NULL order_delivered_customer_date? Which statuses do those orders have?

SELECT ORDER_STATUS,COUNT(*) AS ORDER_COUNT
FROM ORDERS
WHERE ORDER_DELIVERED_CUSTOMER_DATE IS NULL
GROUP BY ORDER_STATUS
ORDER BY ORDER_COUNT DESC;

4.List the 10 most recent orders by purchase date.

 SELECT *
 FROM ( SELECT ORDER_ID,CUSTOMER_ID,ORDER_STATUS,ORDER_PURCHASE_TIMESTAMP
 FROM ORDERS
 ORDER BY ORDER_PURCHASE_TIMESTAMP DESC)
 WHERE ROWNUM<= 10;

5. Self-join orders on customer_id to list pairs of orders from the same customer.

SELECT O1.CUSTOMER_ID,
       O1.ORDER_ID AS ORDER_1,
       O2.ORDER_ID AS ORDER_2,
       O1.ORDER_PURCHASE_TIMESTAMP AS ORDER_1_DATE,
       O2.ORDER_PURCHASE_TIMESTAMP AS ORDER_2_DATE
FROM ORDERS O1
JOIN ORDERS O2 ON O1.CUSTOMER_ID = O2.CUSTOMER_ID
              AND O1.ORDER_ID < O2.ORDER_ID
ORDER BY O1.CUSTOMER_ID;
